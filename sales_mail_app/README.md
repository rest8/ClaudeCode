# 営業メール自動化（ターミナル版デスクトップアプリ）

新規開拓の企業調査から、営業メール・フォローメールの送信、返信／契約状況の管理までを1つの画面で行う
Windows / macOS / Linux 向けアプリです。**デスクトップのアイコンをダブルクリックするとターミナルが開き、
その中ですべての情報（企業リスト・調査・送信・フォロー・テンプレート・履歴・設定）を管理できます。**
（Python + Textual、データはPC内の SQLite に保存。マウスでもキーボードでも操作できます）

## 主な機能

| 機能 | 内容 |
| --- | --- |
| **調査地域の選択（新規開拓）** | 地方→都道府県のチェックボックスと市区町村・業種キーワードで地域を指定し、Googleマップ（Places API）または AI Web検索（Claude）で企業を調査。公式サイトを巡回して公開されている問い合わせ用メールアドレスを取得します。 |
| **送付済みの会社は対象外** | 新規メールの対象は「未送付」の企業だけ。過去に送ったメールアドレスや同じ会社ドメインへの送信、調査結果で既に登録済みの企業は自動で除外し、送信直前にも再確認します。 |
| **送付済み企業へのフォローメール** | 「前回送信から○日以上経過」「フォロー○回まで」の条件で送付済み企業を抽出し、フォロー用テンプレートで送信。前回メールへの返信（Re:）としてスレッド化できます。受信トレイ（IMAP）を確認して、返信があった企業は自動でフォロー対象から外します。 |
| **契約済み企業の除外** | 「契約済みにする」で一覧（既定表示）・新規・フォローのすべての送信対象から除外。既存顧客リストを CSV で「契約済み」として一括取り込みもでき、同じドメインの企業を後から調査しても再登録・誤送信されません。 |

そのほか、テンプレート編集（差し込み項目つき）、AI による企業ごとの文面個別化、テストモード、送信間隔・1日の送信上限、送信履歴と CSV 書き出し、配信停止依頼・不達メールの自動判定に対応しています。

### ステータスと送信対象

| ステータス | 新規メール | フォローメール | 一覧（既定表示） |
| --- | --- | --- | --- |
| 未送付 | ✅ 対象 | – | 表示 |
| 送付済み | ❌ 対象外 | ✅ 対象（日数・回数の条件あり） | 表示 |
| 返信あり | ❌ | ❌ | 表示 |
| 送信エラー | ❌ | ❌ | 表示 |
| **契約済み** | ❌ | ❌ | **非表示（除外）** |
| 配信停止 | ❌ | ❌ | 非表示（除外） |

## インストールとデスクトップアイコン

### Mac で使う（おすすめ）

1. **ダウンロード** – GitHub の **Actions → 「Build Sales Mailer desktop app」** で、緑のチェックが付いた最新の実行結果を開き、
   ページ下部「Artifacts」の **`SalesMailer-macOS`** をクリックします（GitHub へのログインが必要）。
   ダウンロードした zip を開くと `SalesMailer-macOS.dmg` が出てきます。
2. **インストール** – `SalesMailer-macOS.dmg` をダブルクリックし、開いたウィンドウの **`SalesMailer` を `Applications` へドラッグ**します。
   同じウィンドウの「はじめにお読みください.txt」にも手順があります。
3. **初回だけの許可** – 「アプリケーション」フォルダの `SalesMailer` をダブルクリック →「“SalesMailer”は開けません」で「完了」→
   アップルメニュー →「システム設定」→「プライバシーとセキュリティ」の下の方にある **「このまま開く」** をクリック（パスワード入力）→
   もう一度 `SalesMailer` をダブルクリックして「開く」。**ターミナルが開いてアプリが起動します。**
4. **デスクトップにアイコン** – 「デスクトップにアイコンを作成しますか？」で「作成する」。
   「“ターミナル”から“デスクトップ”フォルダ内のファイルにアクセスしようとしています」と出たら「許可」。
   デスクトップの **「営業メール自動化」** をダブルクリックすると、次回からはすぐ起動します。

- タブはマウスでクリックして切り替えます（キーボードでは `fn` + `F1`〜`F7`）。終了は `control` + `Q`。
- Apple シリコン（M1 以降）の Mac 用です。Intel の Mac では動きません。
- 「このまま開く」が表示されない場合は、ターミナルで `xattr -dr com.apple.quarantine /Applications/SalesMailer` を実行してから開いてください。

### Windows で使う

1. 同じ Artifacts から **`SalesMailer-Windows`** をダウンロードし、zip から `SalesMailer.exe` を取り出して置き場所（例: `ドキュメント\SalesMailer\`）に移します。
2. ダブルクリックするとターミナルが開いて起動し、**「デスクトップにアイコンを作成しますか？」** と聞かれるので「作成する」を選びます。
   SmartScreen の警告が出たら「詳細情報」→「実行」を選びます（署名なしのアプリのため）。
3. 次回からはデスクトップの **「営業メール自動化」** アイコンをダブルクリックするだけで起動します。

| OS | 作られるアイコン | クリックすると |
| --- | --- | --- |
| macOS | `営業メール自動化.command` | ターミナル.app が開いて起動 |
| Windows | `営業メール自動化.lnk`（ショートカット） | Windows ターミナル（またはコマンドプロンプト）が開いて起動 |
| Linux | `sales-mailer.desktop`（アプリ一覧にも登録） | 端末が開いて起動 |

実行ファイルを別の場所に移した場合は、設定タブの「デスクトップにアイコンを作成」でアイコンを作り直してください。

### ソースから使う

Python 3.10 以上をインストールして、`install_windows.bat`（Windows）または `./install_mac_linux.sh`（macOS / Linux）を実行すると、
ライブラリのインストールとデスクトップアイコンの作成まで行います。手動で行う場合:

```bash
cd sales_mail_app
pip install -r requirements.txt
python run_app.py --install-shortcut
```

起動オプション: `python run_app.py`（ターミナル版）／`--tab follow`（指定タブで開く）／`--gui`（従来のウィンドウ版）

### 自分で実行ファイルを作る

- Windows: `build_windows.bat` をダブルクリック → `dist\SalesMailer.exe`
- macOS: `./build_mac.sh` → `dist/SalesMailer`（Mac 版の配布用ディスクイメージは CI で作成）

## ターミナル画面の操作

| キー | 操作 |
| --- | --- |
| `F1`〜`F7` | タブ切り替え（企業リスト／新規開拓／新規メール／フォロー／テンプレート／送信履歴／設定） |
| `Tab` / `Shift+Tab` | 入力欄・ボタン間の移動（マウスのクリックでも操作できます） |
| `↑` `↓` | 表の行を移動 |
| `Space` | 表の行にチェック（✓）を付ける／外す。`Ctrl+A` で全チェック |
| `Enter` | 企業の編集（企業リスト）、ボタンの実行 |
| `a` `e` `c` `s` `Del` | 企業リストで 追加／編集／**契約済みにする**／ステータス変更／削除 |
| `i` / `x` | CSV 取り込み／書き出し（ファイルはターミナルにドラッグ＆ドロップするとパスが入ります） |
| `Ctrl+S` | 設定・テンプレートの保存 |
| `Ctrl+Q` | 終了 |

企業リストの操作は「チェックした企業」（チェックが無ければカーソル行）が対象です。送信はチェックした企業だけに行います。
画面は 120×30 文字以上のターミナルを想定しています（Windows ターミナルの標準サイズ）。

## 初期設定（「設定」タブ・F7）

1. **メール送信（SMTP）** – Gmail の場合は `smtp.gmail.com` / `587` / `starttls`。Googleアカウントで2段階認証を有効にし、
   [アプリパスワード](https://myaccount.google.com/apppasswords)を発行してパスワード欄に入力します。「接続テスト」で確認できます。
2. **返信チェック（IMAP）** – Gmail は `imap.gmail.com` / `993`。ユーザー名・パスワードは空欄なら SMTP と同じものを使います。
3. **送信者情報** – 送信者名・会社名・住所・電話番号などは、メール末尾の署名と配信停止の案内として自動で付きます。
4. **企業調査・AI**（使う機能のみ）
   - Google Places API キー: [Google Cloud](https://console.cloud.google.com/) で「Places API (New)」を有効にして発行。
   - Anthropic API キー: [Claude Console](https://platform.claude.com/) で発行。AI 文面個別化と AI Web 調査で使います（既定モデル `claude-opus-5-5`）。

## 使い方の流れ

1. **F2 新規開拓** – 調査地域にチェック（地方の行を選ぶとまとめて選択）を入れ、業種キーワード（例: `製造業, 建設会社`）を入力して
   「▶ 調査開始」。判定が「新規」の企業を「新規をすべてチェック」→「チェックした企業をリストに追加」で登録します
   （送付済み・契約済みなど登録済みの企業は灰色で表示され、追加されません）。既存の企業リストは F1 の「CSV取込(i)」も使えます。
2. **F3 新規メール** – 地域・業種で絞り込んで「対象を抽出」→ プレビューを確認 →「自分宛テスト」で確認 →「▶ 新規メールを送信」。
   送信した企業は自動で「送付済み」になり、次回から新規メールの対象外になります。
3. **F4 フォロー** – 「受信トレイを確認（IMAP）」で返信・配信停止・不達を反映してから「対象を抽出」→ 送信。
   「対象」で「0回（初回フォロー）」などを選ぶと、対応するテンプレート（フォロー1回目／2回目）が自動で選ばれます。
4. **契約が決まったら** – F1 企業リストで企業を選び `c`（契約済みにする）。一覧と送信対象から除外されます。

## CSV の形式

1行目に列名を入れてください（UTF-8 / Shift_JIS どちらも可）。認識する列名の例:

`会社名`（必須）, `メールアドレス`, `Webサイト`, `電話番号`, `住所`, `都道府県`, `市区町村`, `業種`, `担当者名`, `ステータス`, `備考`, `最終送信日`

取り込み時に「未送付／送付済み／契約済み／配信停止」のどれとして登録するかを選べます。
既存顧客リストを「契約済み」で取り込むと、リストと送信対象から除外されます。

## データの保存場所

| OS | フォルダ |
| --- | --- |
| Windows | `%APPDATA%\SalesMailer` |
| macOS | `~/Library/Application Support/SalesMailer` |

`sales_mailer.db`（企業リスト・送信履歴・テンプレート）と `settings.json`（設定。パスワード・APIキーを含む）が保存されます。
バックアップはフォルダごとコピーしてください。

## 送信時の注意

- 営業メールには特定電子メール法（特定電子メールの送信の適正化等に関する法律）が適用されます。送信者の氏名・名称、住所、
  問い合わせ先、配信停止の方法の表示が必要です（設定の「送信者情報」から自動で付与されます）。
  公開アドレス宛でも、サイトに「営業メールお断り」等の記載がある企業には送らないでください。
- 配信停止の依頼があった企業は「配信停止」にしてください（返信チェックで自動判定もされます）。
- 大量送信は迷惑メール判定やアカウント停止の原因になります。送信間隔（30秒以上推奨）と1日の上限を設定してください。
- Web サイトの巡回は robots.txt に従い、1社あたり数ページ・間隔を空けて取得します。

## 開発者向け

```bash
cd sales_mail_app
pip install -r requirements-dev.txt
python -m pytest -q
```

| ファイル | 役割 |
| --- | --- |
| `sales_mailer/db.py` | 企業・送信履歴・テンプレート（SQLite）、新規／フォロー対象の抽出と除外ルール |
| `sales_mailer/research.py` | Google Places 検索、公式サイトからのメールアドレス取得 |
| `sales_mailer/ai.py` | Claude による文面個別化・AI Web 調査 |
| `sales_mailer/campaign.py` | 一括送信ジョブ（送信直前の再確認、送信上限、エラー処理） |
| `sales_mailer/replies.py` | IMAP で返信・配信停止・不達を判定 |
| `sales_mailer/services.py` | 画面から共通で使う処理（調査の実行、リストへの追加、送信確認文） |
| `sales_mailer/shortcut.py` | デスクトップアイコン（.lnk / .command / .desktop）の作成 |
| `sales_mailer/tui/` | ターミナル版の画面（Textual） |
| `sales_mailer/gui/` | ウィンドウ版の画面（Tkinter、`--gui` で起動） |

AI 機能は `anthropic` SDK を使い、安全性フィルタで応答が拒否された場合に別モデルへ自動で切り替える
server-side fallback（`fallbacks="default"`）を有効にしています。
