# ClaudeCode

This repository hosts the **Omakase Notifier** — a Windows-resident
service that watches [omakase.in](https://omakase.in/) for newly opened
reservation slots and pushes a notification (email / LINE) to each
subscribed user.

See [`omakase_notifier/README.md`](./omakase_notifier/README.md) for
installation, configuration, and the admin-console command reference.
